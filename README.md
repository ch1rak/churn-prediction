# Прогноз оттока клиентов

проект: модель предсказывает, уйдёт ли клиент телеком-компании (классификация, обучение с учителем).

Данные: [Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) с Kaggle. Файл `WA_Fn-UseC_-Telco-Customer-Churn.csv` нужно скачать и положить в папку проекта.
